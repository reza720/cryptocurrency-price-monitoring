# Sprint 1 — Sprint Retrospective Meeting Report

## Meeting Information
- **Meeting Type:** Sprint Retrospective Meeting
- **Sprint:** Sprint 1
- **Host:** Reza Panahi

## Participants
- Reza Panahi
- Ghulam Mahfoz Osmani
- Ainullah Amery
- Atifa Rahimi

## Meeting Objective
The objective of the meeting was to reflect on the team's workflow during Sprint 1, identify problems encountered during development and collaboration, and agree on improvements to ensure smoother teamwork in the next sprint.

## Discussion Summary
At the beginning of the meeting, Reza Panahi hosted the session and explained the purpose of the Sprint Retrospective Meeting. He invited the team members to discuss the problems they encountered during Sprint 1 and identify areas where the team's development workflow could be improved.

Reza discussed several issues that occurred during the sprint. These included uploading files in unsuitable formats, such as PDF files, when other formats were more appropriate for the project; pushing code to the GitHub repository using incorrect GitHub accounts; and writing unclear or inappropriate commit messages that did not accurately describe the changes made.

The team discussed how these issues affected project organization, collaboration, and the management of the GitHub repository. Reza explained the importance of following the agreed project requirements, using appropriate file formats, ensuring that Git commits were made from the correct GitHub accounts, and writing clear, meaningful commit messages.

During the discussion, Reza encouraged each team member to take responsibility for correcting these issues. He explained that team members should verify their Git configuration before pushing code, check file formats before uploading files, and follow consistent commit message practices to make the project's development history easier to understand.

The participants discussed these problems and the necessary corrective actions. Reza clarified the expected practices and encouraged everyone to follow them in future sprints to prevent similar issues from recurring.

Finally, the team agreed to improve its file management, GitHub account configuration, and commit message practices. The meeting concluded with a shared understanding of the problems encountered during Sprint 1 and the improvements expected from each team member in the upcoming sprint.
